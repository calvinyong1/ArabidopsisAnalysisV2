Root phenotyping,

A GUI pipeline for segmenting and measuring root and hypocotyl growth from Arabidopsis and tomato timelapse plates — image alignment, nnU-Net segmentation, and per-plant growth curves, end to end.

MainRootLength & HypocotylLength plate3 / plant_2

Three GUI apps, each with its own run.py

imageAligner

Aligns raw plate timelapses frame to frame before segmentation. Falls back to an identity transform when a reference-frame marker can't be found, so one bad frame doesn't block the whole plate.

segmentationApp

Runs nnU-Net inference over aligned frames — root, lateral root, hypocotyl, seed, leaf, and petiole classes — with GPU detection and a CPU fallback.

singlePlantAnalysis

Turns segmentation masks into per-plant growth curves — main/lateral root length, lateral count, hypocotyl length — and generates the final report.

Recent fixes to the analysis pipeline

2026-09-03

Hypocotyl selection no longer borrows a neighboring plant's blob

Added a horizontal-distance cutoff to hypocotyl component selection, so a neighbor's hypocotyl can no longer get picked just because it's the only trackable blob inside a wide ROI.

2026-08-24

Report generation no longer crashes on fresh installs

Pinned a transitive dependency that had started breaking scikit-fda on solve, and made FPCA import failures non-fatal so the rest of the report still generates.

2026-08-19

Growth curves respect the real capture interval

The hourly-resample reconciliation was hardcoded for a 15-minute capture interval, truncating charts at any other interval. It now derives expected row count from the configured timeStep.

2026-08-19

Hypocotyl length no longer zeroed before root detection

HypocotylLength was discarded to 0 on every frame where the root graph wasn't valid yet, even though it's computed independently. The real value now survives every early-return path.
